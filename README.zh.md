# openClockClock24

中文 | [English](README.md)

开源复刻 ClockClock 24 动态时钟：24 个指针表排成 8 × 3 的网格，每个表有两根一样长的指针。所有表合起来显示当前时间，每到整分钟前，所有指针按一段编排好的动作转动，正好在整分时停在新的时间上。

现在是网页版。在线体验：https://jtydhr88.github.io/openClockClock24/

许可证：MIT。

点"纯净模式"只显示时钟，Esc 退出；网址后加 `?pure` 打开就直接进入，适合挂在屏幕上当摆件。

## 运行

```bash
npm install
npm run dev     # 开发服务器
npm test        # 单元测试（node --test）
npm run build   # 打包到 dist/
```

## 原理

### 1. 字形：每个数字由 2 × 3 个表组成

四位数字（HHMM）各占两列，正好 8 列。每个表只有两根指针，每根指针从中心指向上、右、下、左之一，拼出数字的一段笔画。角度从 12 点开始顺时针计：上 0°、右 90°、下 180°、左 270°。

```
"0"  ┌ ┐     [右,下] [左,下]
     │ │     [上,下] [上,下]
     └ ┘     [上,右] [上,左]
```

不需要笔画的格子，两根指针重叠指向 7 点半（225°），看起来像一根斜线，等于"熄灭"。实物照片里的 "1" 左列就是这样。

一个表最多画两段笔画，所以 3、4、6、8、9 中间需要三个方向的位置会留缺口，实物也一样（例如 8 是上下两个方框叠在一起）。字形表在 `src/glyphs.js`。

### 2. 时间到目标角度

`layoutText("1850")` 把四个字符查表，得到 24 个格子各自两根指针的目标角度。

### 3. 动作：每根指针一条时间线

指针角度不取模，可以超过 360°，所以"顺时针多转一圈"就是 +360。每根指针是一条 `Track`：一串"等待 / 转到某角度（带缓动）"的片段。

- `cwTo(当前, 目标, 圈数)`：顺时针走到目标，可加整圈
- `ccwTo`：逆时针
- 两根指针一顺一逆，就会出现实物那种剪刀状的开合

一个"动作编排"就是给 48 条时间线排程，按列、按到中心的距离、按对角线加延迟，就有了波浪、涟漪等效果。分阶段的动作（先全部变成同一条斜线，一起转一圈，再散开成数字）用 `sync()` 让所有指针等最慢的那根完成再进入下一阶段。不管中间怎么转，最后都必须停在目标角度上，测试会逐个检查。

现在有 6 种动作：直接转到、对向扫过、斜线齐转、中心涟漪、放射绽放、垂落瀑布。都在 `src/choreographies.js`，加一种就是加一个 `build(cells)` 函数。

### 4. 按整分对时

动作的总时长事先就能算出来，所以在 `下一个整分 - 时长` 那一刻开动，动作结束时正好跳到新的一分钟。

## 目录

| 文件 | 内容 |
|---|---|
| `src/glyphs.js` | 数字字形表、时间转格子 |
| `src/motion.js` | 角度计算、缓动、`Track` 时间线 |
| `src/choreographies.js` | 动作编排 |
| `src/render3d.js` | 拟物 3D 绘制（Three.js：开孔面板、凹碗、实时阴影、环境反射，可拖动视角） |
| `src/render.js` | 平面 Canvas 绘制 |
| `src/main.js` | 调度（时钟 / 自定义 / 演示模式）和界面 |
